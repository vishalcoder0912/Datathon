# KAVACH AI Method Reference

This legacy filename is retained for existing links. The authoritative methods document is [ANALYTICS_METHODS.md](ANALYTICS_METHODS.md).

The current platform uses PostGIS/DBSCAN hotspot clustering, rolling-baseline spike alerts, IQR and Z-score baselines, Isolation Forest when data is sufficient, aggregate geographic risk factors, NetworkX graph metrics, and structured/trigram modus-operandi similarity. Every result contains its evidence, time window, record count, confidence, limitations, and human-review requirement.

No individual risk score, recidivism score, age-based score, guilt prediction, or protected-attribute model is implemented.
